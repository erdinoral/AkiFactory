                              Ses Donustur (RVC)

                              Uzun bir ses kaydini yukle, hedef RVC modelini sec. Kaynak telaffuz korunur; sadece ses karakteri degisir.

                              En iyi sonuc icin
                              • En temiz yol: Uret sekmesinde RVC ile video uret — once Edge metni okur, sonra modele donusturulur.
                              • Kaynak: tek kisi, sessiz ortam, arka plan muzigi yok.
                              • Format: WAV veya yuksek bitrateli MP3; mono veya stereo olabilir.
                              • Model orani: 0.65–0.85 (varsayilan 0.75) — 1.0 bazen bozuk/robotik yapar.
                              • Pitch: erkek ses → erkek model, kadin ses → kadin model; uyumsuzsa ±2–4 dene.
                              • 2 dakikadan uzun kayitlarda donusum birkaç dakika surebilir.

                              WAV, MP3, M4A… (en fazla 80 MB)

                              RVC modeli yok — Ayarlar veya models/rvc/ klasorune .pth ekleyin.

                                    API anahtari nasil alinir?

                                    Pexels

                                    Ucretsiz: ~200 istek/saat, 20.000 istek/ay (anahtar basina)

                                    Kayit / anahtar sayfasi · Dokumantasyon

                                    1. pexels.com/api/new adresine git
                                    2. Ucretsiz hesap olustur veya giris yap
                                    3. Formu doldur (proje adi: AkiFactory / kisisel kullanim yeterli)
                                    4. E-posta ile gelen API anahtarini kopyala
                                    5. Asagidaki Pexels kutusuna yapistir → Kaydet → Test et

                                    Pixabay

                                    Ucretsiz: ~100 istek / 60 saniye (anahtar basina)

                                    Kayit / anahtar sayfasi · Dokumantasyon

                                    1. pixabay.com uzerinde ucretsiz hesap ac
                                    2. pixabay.com/api/docs sayfasina git (giris yapili olmali)
                                    3. Sayfanin ustundeki ornek kodda senin API anahtarin gorunur
                                    4. Anahtari kopyala (rakam ve harfler, tireli uzun metin)
                                    5. Pixabay kutusuna yapistir → Kaydet → Test et
                                    • Her kullanici kendi ucretsiz anahtarini almali — paylasilan anahtar kota biter.
                                    • Anahtarlar yalnizca bu bilgisayarda data/api_keys.json icinde saklanir; kurulum paketine girmez.
                                    • Iki servis de ucretsiz; kredi karti gerekmez.

                                    Durum: yukleniyor…

                                    Telegram bildirimleri

                                    Video veya kuyruk bitince telefonuna mesaj gelir. Ayarlar bu bilgisayarda saklanir — kurulum paketine gitmez.

                                    Telegram bot nasil kullanilir?

                                    Bildirim botu: @AkiFactory_bot · @BotFather (yalnizca kendi botun icin)

                                    Hizli kurulum (paylasilan bot)

                                    1. Telegram'da @AkiFactory_bot botunu ac (BotFather degil).
                                    2. Bota /start yaz — bu adim zorunlu, yoksa mesaj gitmez.
                                    3. Bot token kutusuna paylasilan bot token'ini yapistir → Kaydet (kendi botun varsa onun token'i).
                                    4. Chat ID bul — senin Telegram kullanici ID'n otomatik gelir ve kaydedilir.
                                    5. Test gonder ile telefonuna deneme mesaji dus.

                                    Kendi botun (istege bagli)

                                    1. Telegram'da @BotFather ac → /newbot ile yeni bot olustur.
                                    2. Verilen token'i asagidaki Bot token kutusuna yapistir → Kaydet.
                                    3. Kendi botuna /start yaz → Chat ID bul → Test gonder.

                                    Baska birine bildirim (farkli kullanici)

                                    1. Her kullanici kendi telefonundan bota /start yazmali.
                                    2. O kisi kendi AkiFactory kurulumunda Chat ID bul yapar (veya ID'yi sana iletir).
                                    3. Ayni bot token paylasilabilir; Chat ID kisi basina farklidir.
                                    4. Senin Chat ID'n pakete gitmez — data/telegram.json yalnizca o PC'de kalir.

                                    Ne zaman mesaj gelir?

                                    • Her video hazir olunca (aciksa)
                                    • Uretim kuyrugu tamamen bitince (aciksa)
                                    • BotFather'a /start yazma — bildirim botuna yaz.
                                    • Token ve Chat ID kurulum paketine dahil edilmez.
                                    • Bildirimler kapaliysa mesaj gonderilmez.

                                    Once bota /start yaz, sonra Chat ID bul.
